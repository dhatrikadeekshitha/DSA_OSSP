# Skill_04 - Interactive Loop and Keyboard Input

## Objective

To create an interactive command loop that displays a prompt,
captures keyboard input, handles backspace, processes the Enter key,
manages an input buffer, supports multi-character commands, and
handles exit conditions.

## Features

- Main interactive loop
- Display prompt
- Read keyboard input
- Handle Backspace
- Process Enter key
- Manage input buffer
- Support multi-character commands
- Handle exit condition
- Handle unknown commands

## Commands

help
hello
status
exit

## Compilation

gcc interactive_loop.c -o interactive_loop

## Execution

./interactive_loop
