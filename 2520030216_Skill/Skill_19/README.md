# Skill-19 – Job Listing and Foreground Switching

## Objectives

1. List active jobs, display status information, retrieve job IDs,
   format output, update state information, and test job listings.

2. Identify the target job, transfer terminal control, resume processes,
   wait for completion, update job state, and test foreground switching.
