SYSTEM CALLS AND USER SPACE-KERNEL SPACE INTERACTION

1. FILE COPYING USING SYSTEM CALLS

The C program copies the contents of one file to another using the
system calls open(), read(), write(), and close().

System calls used:

open():
The open() system call opens the source and destination files and
returns file descriptors.

read():
The read() system call reads data from the source file into a buffer.

write():
The write() system call writes the data from the buffer into the
destination file.

close():
The close() system call closes the files after the copying operation
is completed.

2. USER SPACE AND KERNEL SPACE

The C program runs in user space. When the program needs an operating
system service, it makes a system call.

The control flow is:

User Program
     |
     | open()
     v
Operating System Kernel
     |
     v
File System / Storage

User Program
     |
     | read()
     v
Operating System Kernel
     |
     v
File Data

User Program
     |
     | write()
     v
Operating System Kernel
     |
     v
Destination File

User Program
     |
     | close()
     v
Operating System Kernel

The kernel performs the requested operation and returns the result
back to the user-space program.

3. STRACE ANALYSIS

The Linux command used for tracing is:

strace cat sample.txt

The strace utility displays the system calls made by a program.

Important system calls generated while executing cat include:

execve():
Loads and executes the cat program.

openat():
Opens sample.txt and obtains a file descriptor.

read():
Reads the contents of sample.txt.

write():
Writes the contents to standard output, which is the terminal.

close():
Closes the file descriptor.

exit_group():
Terminates the process.

Typical sequence:

execve()
   |
openat()
   |
read()
   |
write()
   |
close()
   |
exit_group()

4. KERNEL SERVICES INVOLVED

The kernel provides the following services:

1. Process execution
2. File system access
3. File reading
4. Terminal output
5. File descriptor management
6. Process termination

5. CONCLUSION

System calls provide an interface between user applications and the
operating system kernel. The file-copy program uses open(), read(),
write(), and close() to access files. The strace utility in Linux can
be used to observe the system calls generated by commands such as cat.
This demonstrates how user programs request services from the kernel.
